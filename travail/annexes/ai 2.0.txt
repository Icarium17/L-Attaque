		update_belief_state() : si applicable, va changer le belief state de la piece qui a joue ou qui est decedee ** a faire aussi pendant le combat
		initialise un MCTS

MCTS
	algo() : démarre l'algo
		it = current iteration
		creates an initial_info_set
		creates node_0 with initial_info_set
		final = false
		while it >= 0
			new_determination() : creates a new Determination, checks if its consistent with initial_info_set
			selection() : while node != leaf, calls apply_UCT(): which calculates the node's best child_node or best possible move
			while !final:	
				simulation() : calls expand_node() : randomly select a possible move, checks check_final() (returns true after every move to see if the flag has been captured or if the opponent has no more moves
				if check_final is true or simulation has no possible children : final = true
			calculate_value() : calculate the value of the resolution
			backpropagation(): from either the list of paths taken to get to the final node or using the parent property of the nodes, backpropagate the value of the final node
			it -= 1
			final = false
		return node_0.get_best_child().move_from_parent

Node
	get_best_child() : gets the child with the best value
	uct() : calculate the uct for all existing children
	generate_possible_moves() : when the node is created, will fill the possible_children list
	is_fully_expanded() : checks if possible_children is empty
